# Field Inhomogeneity

Field-inhomogeneity-corrected model-based reconstruction for a water-filled phantom with four identical acetone-water inserts, compared against an uncorrected reconstruction and a retrospectively undersampled compressed-sensing variant.

## Run

To run the experiment, follow the following bash commands:
```bash
chmod +x run.sh
./run.sh
```

Results are written to `data/results/field-inhomogeniety/`.
