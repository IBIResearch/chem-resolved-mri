# Multi-Peak Spectra

Model-based chemically resolved MRI reconstruction for a water-filled phantom with four inserts containing ethanol-acetone mixtures at different acetone molar ratios. The reconstruction uses a multi-peak spectral model for ethanol and compares the estimated component maps against known mixture compositions.

## Run

To run the experiment, follow the following bash commands:
```bash
chmod +x run.sh
./run.sh
```

Results are written to `data/results/multi-peak-spectra/`.
